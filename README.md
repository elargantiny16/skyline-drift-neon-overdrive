# Skyline Drift: Neon Overdrive

A premium browser-based arcade game built for Hack Club: The Game.

## 🎮 Gameplay
You drive through a futuristic neon highway, avoiding traffic, collecting crystals, and building combo chains through high-speed near misses.

## ⚡ Features
- Pseudo-3D road rendering
- Dynamic traffic system
- Combo & boost mechanics
- Neon cyberpunk visual style
- Mobile + desktop controls
- No external libraries (pure HTML/CSS/JS)

## 🕹 Controls
- Left / Right arrows → Move
- A / D → Move
- Space → Boost
- P → Pause
